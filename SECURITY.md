# Security Policy

## Supported Versions

This is a single-branch template, not a versioned library — there's no
support matrix. Security fixes land on `main`; if you've deployed a fork,
pull the latest changes to pick them up.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](https://github.com/zloether/serverless-mcp-server/security/advisories/new)
rather than filing a public issue. Include:

- A description of the issue and its potential impact
- Steps to reproduce (or a minimal example)
- Any relevant logs or configuration (redact secrets/account IDs)

This is a personal-scale template maintained on a best-effort basis — there's
no guaranteed response SLA, but reports will be triaged as soon as possible.
